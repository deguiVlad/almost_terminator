# arm_ik — обратная кинематика рук TienKung 2.0 Pro

Выводит кончик каждой 7-DOF руки в заданную позу (позиция + ориентация) относительно `pelvis`.

- Модель руки строится из URDF в `/robot_description`: те же суставы, оси, смещения и пределы, что у
  симулятора. Поворот корпуса (`body_yaw_joint`) берётся из `/joint_states`, так что IK верна и при
  повёрнутом корпусе.
- IK: затухающие наименьшие квадраты (DLS) в пределах суставов с запасом 0.05 рад (чтобы приводу оставался
  ход на дотягивание); суставы, упёршиеся в предел, исключаются из шага, а не тормозят решение. Старт из
  текущей позы, средней позы и нескольких случайных; из подходящих решений выбирается ближайшее к текущей позе.
- Если вся поза недостижима, позиция решается в приоритете, а ориентация — ближайшая возможная
  (нуль-пространство позиционной задачи). Рука едет, в логе — на сколько промахнулась ориентация.
  Если недостижима и позиция, но промах не больше `max_miss` (3 см), рука едет в ближайшую точку; дальше —
  цель отклоняется, рука остаётся на месте, нода продолжает принимать цели.
- Исполнение: одна команда в `/arm/cmd_pos`, скорости суставов согласованы (все приходят одновременно,
  максимум 0.8 рад/с). Когда рука остановилась, нода сравнивает углы из `/joint_states` с решением и
  сдвигает команду на долю ошибки — так компенсируется недолёт ПД-приводов под весом руки.
- Зависимости: только numpy и стандартные пакеты ROS 2 Humble.

## Сборка и запуск

```bash
colcon build --packages-select arm_ik
source install/setup.bash
ros2 launch arm_ik arm_ik.launch.py
```

## Интерфейс

| Топик | Тип | |
|---|---|---|
| `/arm_ik/goal_left`, `/arm_ik/goal_right` | `geometry_msgs/PoseStamped` | цель кончика; рамка любая из TF, пустая = `pelvis` |
| `/arm_ik/delta_left`, `/arm_ik/delta_right` | `geometry_msgs/TwistStamped` | 6D-смещение кончика: `linear` — сдвиг, м; `angular` — поворот (ось × угол), рад |
| `/arm_ik/left/status`, `/arm_ik/right/status` | `std_msgs/String`, JSON | `state`: `idle` / `moving` / `reached` / `stopped`; `orient`: `full` (вся поза) / `secondary` (позиция точно, ориентация — ближайшая) / `none`; `err_pos` (м), `err_rot` (рад); `rejected` — последняя отклонённая цель |
| `/arm_ik/wrist_left_pose`, `/arm_ik/wrist_right_pose` | `geometry_msgs/PoseStamped` | текущая поза кончика по энкодерам |
| `/arm/cmd_pos` | `bodyctrl_msgs/CmdSetMotorPosition` | команды моторам 11–17 / 21–27 |

Пример: правая рука в точку перед собой (подставьте свою высоту и ориентацию).

```bash
ros2 topic pub --once /arm_ik/goal_right geometry_msgs/msg/PoseStamped \
  "{header: {frame_id: pelvis}, pose: {position: {x: 0.35, y: -0.25, z: 0.25}, orientation: {w: 1.0}}}"
ros2 topic echo /arm_ik/right/status
```

Если ориентация не важна (или сначала нужно просто проверить досягаемость), запускайте с
`rot_weight:=0.0` — тогда IK решает только по позиции.

### 6D-смещение

Смещение считается от последней отправленной цели (`delta_reference:=measured` — от измеренной позы).
Рамка в `header.frame_id`: пусто или `pelvis` — оси корпуса; `tool` (или имя звена-кончика) — оси кисти;
любое другое имя — оси этой TF-рамки. Поворот всегда вокруг кончика: позиция кончика при повороте не меняется.

```bash
# на 5 см вверх и 3 см вперёд в осях корпуса
ros2 topic pub --once /arm_ik/delta_right geometry_msgs/msg/TwistStamped \
  "{header: {frame_id: pelvis}, twist: {linear: {x: 0.03, z: 0.05}}}"
# повернуть кисть на 0.3 рад вокруг её оси x
ros2 topic pub --once /arm_ik/delta_right geometry_msgs/msg/TwistStamped \
  "{header: {frame_id: tool}, twist: {angular: {x: 0.3}}}"
```

### Кисть соосна предплечью

С `wrist_aligned:=true` суставы `wrist_pitch` и `wrist_roll` держатся в нуле (прямая кисть по URDF): кисть
продолжает предплечье и поворачивается вместе с ним, а не висит. Позицию решают остальные 5 суставов точно,
ориентация из цели выполняется, насколько позволяют оставшиеся степени свободы. Параметр читается на каждой
цели, его можно переключать на лету:

```bash
ros2 param set /arm_ik wrist_aligned true
```

## Параметры

| Параметр | По умолчанию | |
|---|---|---|
| `tip_link_left`, `tip_link_right` | `wrist_roll_{l,r}_link` | звено-кончик; можно указать звено ладони из URDF |
| `tcp_offset` | `[0, 0, 0]` | смещение кончика в рамке этого звена, м |
| `rot_weight` | 1.0 | вес ориентации в IK; 0 — только позиция; меняется на лету |
| `wrist_aligned` | false | кисть соосна предплечью; меняется на лету |
| `tol_pos`, `tol_rot` | 0.01 м, 0.05 рад | допуск для `reached` (IK решает с половиной допуска) |
| `max_miss` | 0.03 м | наибольший промах по позиции, с которым рука ещё едет в ближайшую точку |
| `delta_reference` | `goal` | опора смещений: `goal` — последняя цель, `measured` — измеренная поза |
| `kp` | 0.7 | доля ошибки суставов, на которую сдвигается команда при дотягивании |
| `joint_tol` | 0.005 рад | когда дотягивание прекращается |
| `max_corrections` | 15 | предел шагов дотягивания |
| `spd` | 0.8 | максимальная скорость суставов, рад/с |

## Использование как библиотеки

Ядро не зависит от ROS, его можно вызывать прямо из своей ноды:

```python
from arm_ik.kinematics import Arm
arm = Arm(urdf_xml, "right")                     # urdf_xml — строка из /robot_description
ok, q, err_pos, err_rot = arm.solve(T_goal_4x4, q_now, extra=joint_states_dict)
```

проверяется в симуляторе.
